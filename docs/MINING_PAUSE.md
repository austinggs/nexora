Mining has reached the planned pause point after the facility realism pass.

- CPU / motherboard / RAM / GPU compatibility.
- Multi-GPU topology and powered-riser validation.
- Multi-PSU capacity and synchronization rules.
- ASIC-specific rig path.
- Server-authoritative hash rate, thermal, overclock, mining events and gremlins.
- Facility voltage, phase, service-amperage, ambient temperature, airflow, exhaust and active-cooling model.
- Rig/facility evaluation and overload/failure/recovery state.
- Mining leaderboard, prestige and Ghost Rig foundations.

Do not add new mining mechanics until the project roadmap calls for a mining resumption. Continue with the next non-mining project phase instead.
